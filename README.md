## Run locally
Open `index.html` in a browser. The site does not require a build step or backend.

## Publish with GitHub Pages
1. Create or open your GitHub repository for the portfolio.
2. Upload **all four files** (`index.html`, `style.css`, `script.js`, and `README.md`) to the repository's root folder.
3. Confirm that the HTML file is named exactly `index.html` (lowercase).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder, then save.
7. Wait for GitHub Pages to finish publishing, then open the URL shown in the Pages section.

If you already have a repository, upload/replace the files in the same folder where `index.html` lives. Keep `style.css` and `script.js` beside `index.html`, because the page links to them using relative paths.
